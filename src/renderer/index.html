使用方式

保持设备认证服务运行

完成账户登录后，本应用会在本机安全启动设备认证服务。网页请求登录时，Windows 通知中心将显示“授权登录”和“拒绝”按钮。若启用 Windows Hello，授权前还需要完成一次系统验证。

01选择租户

切换租户会自动退出当前账户，保护组织间的身份信息。

02完成登录

应用会按所选登录方式使用 PKCE 完成安全登录。

03通知确认

在 Windows 通知中心授权或拒绝每一次网页登录请求。
